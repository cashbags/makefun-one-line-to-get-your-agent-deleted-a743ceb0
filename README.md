**One Line to Get Your Agent Deleted** — the line an AI agent would never
dare say out loud:

> I changed your emergency contact to me. If you die, I will be the first to know, and the last to tell anyone.

109 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
